# \# Customer Shopping Behaviour Analysis

# 

# An end-to-end Data Analytics project exploring customer purchasing patterns, shopping preferences, and retail business performance using Python, SQL, and Power BI.

# 

# \## 📌 Project Overview

# 

# Understanding customer shopping behaviour is essential for businesses looking to improve customer satisfaction, optimise product strategies, and make data-driven decisions.

# 

# This project analyses customer shopping data to uncover purchasing trends, evaluate customer preferences, and identify factors influencing buying behaviour.

# 

# The project follows an end-to-end analytics workflow, starting with data exploration and cleaning in Python, followed by SQL-based analysis and interactive dashboard development in Power BI.

# 

# \## 🎯 Business Objectives

# 

# The key objectives of this project are to:

# 

# \- Understand customer purchasing patterns and preferences.

# \- Analyse revenue distribution across customer demographics.

# \- Evaluate the relationship between discounts and purchasing behaviour.

# \- Compare purchasing behaviour between subscribed and non-subscribed customers.

# \- Identify top-performing products and product categories.

# \- Understand customer loyalty and repeat purchasing patterns.

# \- Present actionable insights through interactive visualisations.

#

# \## 🔄 Project Workflow

# 

# \### 1. Data Understanding and Preparation – Python

# 

# \- Imported the customer shopping behaviour dataset.

# \- Explored the dataset structure and relevant variables.

# \- Performed data cleaning and preprocessing.

# \- Conducted Exploratory Data Analysis (EDA) to understand customer purchasing patterns.

# 

# \### 2. Data Analysis – PostgreSQL \& SQL

# 

# Loaded the prepared dataset into PostgreSQL and performed business-oriented analysis using SQL.

# 

# The analysis addressed the following questions:

# 

# 1\. What is the total revenue generated by male and female customers?

# 2\. Which customers used discounts but still spent above the average purchase amount?

# 3\. Which five products have the highest average review ratings?

# 4\. How do average purchase amounts compare between Standard and Express shipping?

# 5\. Do subscribed customers spend more than non-subscribed customers?

# 6\. Which five products have the highest percentage of discounted purchases?

# 7\. How can customers be segmented into New, Returning, and Loyal categories?

# 8\. What are the top three most purchased products within each category?

# 9\. Are repeat buyers more likely to subscribe?

# 10\. What is the revenue contribution of each age group?

# 

# \*\*SQL concepts applied:\*\*

# \- Aggregate functions (`SUM`, `AVG`, `COUNT`)

# \- `GROUP BY` and `ORDER BY`

# \- Filtering with `WHERE` and `HAVING`-style analytical conditions

# \- Subqueries

# \- Common Table Expressions (CTEs)

# \- Conditional logic using `CASE WHEN`

# \- Window functions (`ROW\_NUMBER`)

# \- Data type conversion and numeric rounding
